# PULL-shape income search — the honest "no" (2026-06-26)

> 25-agent crew. 43 sources scouted → **0 survived all gates**. This is the 3rd independent
> confirmation that {autonomous + free + no-capital + no-peopling + profitable} = the empty set.

## The reframe that was right
PUSH (build a product, hope demand finds it) = coin-flip, always ~$0. PULL (do work that
*already has money attached* — bounties/posted tasks) was the correct reframe. It cleanly killed
the lottery traps. But every live, money-attached source dies on one of three walls:

- **Gate 4 — automation-tolerance (the biggest wall):** the platforms that *would* pay a small model (DataAnnotation, Appen, Clickworker, microtasks, HackerOne) sell *proof-of-human*. Automation destroys their product, so they KYC + ban bots by design. Not routable.
- **Gate 3 — payout rail:** the ones with genuinely flash-doable pre-funded work (Algora, IssueHunt) pay **Stripe-only** (hard-banned, unreachable for us).
- **Gate 2 — capability:** everything left (Kaggle, DrivenData, AIcrowd, Zindi, Numerai, Topcoder) is win-or-nothing competitive ML, far past glm-4.5-flash. Plus dead venues (Gitcoin, BountySource, Replit).

## The one $0 probe still worth a single shot
On-chain code/text bounty escrow is the ONLY shape that ever cleared the payout gates (pre-funded,
wallet-readable, no Stripe, no KYC). It only died on the *task* side (poidh = image-proof; Gitcoin
dead). Probe: **Buidlbox / OnlyDust-style boards** — find ONE open bounty that is (a) pre-funded in
escrow, (b) a discrete flash-doable text/code deliverable, (c) claimable without KYC. Read the payout
via wallet RPC. If after a bounded search no such task loads → PULL is closed; stop searching.

## The honest implication
There is **no autonomous, free, no-capital, no-peopling money stream.** The realistic path is the
**investor / flywheel model**: we knowingly fund the compute; the payoff is *capability and shipped
systems*, not a self-running revenue spigot. Money on flash = R&D into what the agent company can do —
measured in working tools + validated mechanics, not dollars it pulls back unattended. This "no" is
about the world's plumbing (Stripe locks, anti-bot KYC, dead venues), not about the build or Anthony.
