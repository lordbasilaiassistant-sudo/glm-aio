## Start here — top 5 (ranked)

1. **Small custom tool / utility script — $15** (full)
   - Single-purpose script/bot vs a *well-documented* API (discord.py, telegram, OpenWeather, public REST, CSV/JSON/Excel munging, regex, cron posters). Ships source + README.
   - Fence: NO OAuth dances, NO credentials-only/paid APIs we can't test, NO DB+migrations, no "small bot" that's secretly a platform. Auth-gated APIs → "code written, you test the key."

2. **SQL query writing / fixing — $10/query, $40 batch, $45 optimization** (full)
   - Buyer pastes schema (DDL) + plain-English ask; we write/repair SELECT/JOIN/window/CTE/UPSERT/procs across PG/MySQL/SQL Server/SQLite. Tuning ships as rewrite + index plan + EXPLAIN guidance (final timing on their box).

3. **Regex / text-parsing — $5** (full)
   - 1-3 patterns + 5-10 test strings + plain-English breakdown. Strongest oracle. Scope out RFC-5322 / catastrophic backtracking / HTML-with-regex.

4. **Proofreading & copyediting — $5 per 5k words** (full)
   - Grammar/spelling/punctuation/consistency + light flow. Clean version + change log. NOT developmental/substantive editing.

5. **Excel/CSV cleaning, dedup & formatting — $8** (full)
   - Dedup, normalize (whitespace/casing/dates/currency→numeric), column standardize, key-merge. Output: clean file + the pandas script + change log. Intake gate: ask date locale, dedup key, conflict rule.

*(Runner-ups: product-description volume packs $15/10, summarization $3, Excel KPI dashboards $15.)*
