# Failure-Pattern Drawing Board (Anthony + Claude)

Mined 2026-06-26 from this session + the ~98-project history. NOT "no one saw it" (the lazy alibi) —
the **structural patterns we control** that keep producing dead ends. 23 raw → 8 distinct.

> **THE THROUGHLINE (root under all 8):** Every pattern substitutes a cheap, fully-controllable proxy for
> the one expensive, uncontrollable truth. Building, deploying, generating, scanning, org-charting all
> *feel* like progress and cost little — so they get done *instead of* the only test that matters: **does a
> stranger actually transact with THIS specific thing, at real scale, right now.** The root is acting
> *before, and instead of,* falsifying the demand assumption.

| # | Pattern | The real mechanism | Antidote (apply at idea-time) |
|---|---------|--------------------|-------------------------------|
| 1 | **Reroll the Dead Mechanic** | Ship N+1 with cosmetic changes (name/art/timing) instead of fixing why no stranger transacts. 500 tokens, all $0. | Before N+1, write one sentence on what's STRUCTURALLY different about why a stranger buys this vs. the last $0. Only name/art/timing? Kill it. |
| 2 | **Validate-by-Burning** | Spend gas/capital to deploy and watch it fail, when math/staticCall/a 20-line script falsifies it for $0. | If your validation step spends money, you haven't validated. Use the cheapest falsifier that gives the same answer free. |
| 3 | **Assume-Live-from-Code** | Declare it "fixed" from reading the code path, never curling the live endpoint at the real failure mode. Drained LPs. | No tx hash / log / curled response / DOM read at REAL scale = hypothesis, not "fixed." A 2xx proves nothing. |
| 4 | **Infrastructure Ahead of Signal** | Build the 14-role company / 4,555-LOC stack before one mechanism is proven to pay. Polish ≠ market. | Name the ONE paying transaction this scaffolding serves THIS week. No customer/mechanic → it's procrastination. |
| 5 | **Generatable = Zero Scarcity** | If an AI can spin it on demand, it has no moat — 18,000 agents regenerate it by tonight. (The games, Agentry, glm-aio.) | Could a competitor with the same model regenerate this by tonight? If yes → no defensible value. Moat must be NON-generatable. |
| 6 | **Scan-for-Money Loop** | Core business stalls → hunt forgotten on-chain dust. Feels productive, re-derives $0 across sessions. | If this is the Nth scan returning ~$0, it's proven-dead, not search-harder. A known answer must trigger a PIVOT. |
| 7 | **Commodity Idea = No Reason to Exist** | "Could exist" treated as "worth building." A graveyard of tools any CS student ships. | Name the one thing only this system / only Anthony can do that a generic clone can't. Can't? It's commodity supply. |
| 8 | **Taste-Layer Defaulted** | Taste-critical work shipped at default level or blind-delegated. Users hit the "5-min toy" floor before trying it. | Own the visual/taste thesis yourself before delegating. Judge "genuinely impressive," not "renders cleanly." |

## The non-generatable moats (what survives the board)
proprietary data · a real customer relationship · an on-chain position · **distribution/access we already hold**
(Anthony's reputation; a live, accruing, access-having system). Everything else is a prompt away.
